1. Почему в Git ветвление "дешёвое", а в SVN "дорогое"?
Ветка в Git это просто указатель на коммит, создаётся мгновенно и не копирует файлы. В SVN ветка это отдельная директория в репозитории, поэтому операция тяжелее и делается реже.

2. Можно ли в SVN сделать коммит без интернета? Почему?
Нет, нельзя. SVN централизованная система, все коммиты уходят на общий сервер, а без связи с ним зафиксировать изменения невозможно. В Git коммит делается локально, потому что репозиторий есть у каждого целиком.

3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?
Когда нужен жёсткий контроль прав на отдельные папки и файлы, когда в проекте много больших бинарных файлов, и когда команда хочет простую централизованную модель с единым сервером вместо распределённой.
